<h1 align="center">
  Easy Shopping Via Mobile</h1>

<p align="center"> 
  Este foi o meu terceiro projeto durante a formação e representou um novo desafio na minha evolução como desenvolvedor. O layout apresentou elementos mais complexos de reproduzir a partir do Figma, exigindo mais atenção aos detalhes, organização do código e aplicação de novos conceitos em HTML e CSS. </p>

<p align="center"> 
  Cada etapa deste projeto contribuiu para fortalecer minha lógica de desenvolvimento e minha capacidade de transformar um design em uma interface fiel, responsiva e bem estruturada. </p>

<p align="center"> 
  Este projeto foi desenvolvido com os conhecimentos adquiridos ao longo da formação no <a href="https://lp6.rodolfomori.com.br/cap-org-a-v1/?utm_campaign=encurtadoraprendacomigo&_v=019f72c3-1689-7b02-8b8d-d1359e8a8949&_p=019e5077-bd01-7420-900d-fc6e5b6f12af&_c=412ee7fe-d121-4828-b6ac-f8e0cf60bd16&_l=019f72c3-1623-75b1-b90e-8b3bb4d734d9">DevClub</a>. </p>
